# Security Policy

Vault is pre-alpha research software. It has no mainnet, no supported production
release, no audit, and no bug bounty. Do not use it with real assets.

## Reporting

Do not publish a suspected vulnerability before maintainers can assess it. A
dedicated security contact and encrypted reporting key have not yet been
established; that is a release blocker. Until then, report privately to the
repository owner through an already authenticated private channel.

Never include private keys, seeds, personal data, or live-fund transaction
details in a report.

## Required before public testnet

- dedicated `security@` contact and published encryption key;
- response and embargo process with named owners;
- dependency and artifact inventory;
- reproducible release signatures;
- independent cryptography and application audits;
- public advisory and verifier-deactivation procedure;
- funded bug bounty.
